MPK CODEX BRIDGE - CHOOSE ONE VERSION
=====================================

CLASSIC (RECOMMENDED)
Folder: Classic

The original compact interface and original MIDI behavior. Use this version
when reliability and the working pad/knob setup are the priority.

MODERN / REEL VIEW
Folder: Modern - Reel View

The polished visual redesign with guided setup and a dedicated Reel View.

IMPORTANT
---------

Both apps use the same local configuration and listen for the same MIDI
controls. Install and run only one version at a time. Quit MPK Codex Bridge
completely before switching versions.

INSTALL
-------

1. Open the folder for the version you want.
2. Drag MPK Codex Bridge.app to Applications.
3. On first launch, Control-click the app and choose Open.
4. Enable MPK Codex Bridge under:
   System Settings > Privacy & Security > Accessibility

macOS may ask you to enable Accessibility again after switching versions.

Both versions are local-only, need no OpenAI API key, and make no network
requests.
