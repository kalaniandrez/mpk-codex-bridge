# MPK Codex Bridge 1.0.2 Dual Pack

The main download now includes both applications:

- **Classic**, the restored original version and the recommended choice for
  the working MPK setup.
- **Modern / Reel View**, the polished v1.0.0 redesign for visual demos.

Each version is also available as a separate release asset.

## Icon fix

Classic now declares and bundles the custom keyboard-and-knobs macOS icon. It
also has a distinct macOS app identity so Finder and the Dock do not confuse it
with Modern, eliminating the blank Classic icon.

## Important

Both versions share the same local mappings and listen for the same MIDI
controls. Install and run only one at a time. Quit MPK Codex Bridge completely
before switching. macOS may require Accessibility permission again after a
switch.

Both applications are universal Apple silicon and Intel builds. Their code
signatures are verified again after the dual archive is extracted.

Requires macOS 13 or newer and the Codex desktop app. These community builds
are not Apple-notarized, so first launch requires Control-click > Open.

endorsed by OpenAI or Akai Professional.
