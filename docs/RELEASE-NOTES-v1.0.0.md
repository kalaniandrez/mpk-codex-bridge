# MPK Codex Bridge 1.0.0

Turn an Akai MPK Mini Play, or another class-compliant MIDI controller, into a
physical shortcut controller for the Codex desktop app.

## Highlights

- Eight learnable pad actions and four learnable directional knob actions
- Guided setup for MIDI, Accessibility, and control learning
- Reel View with large live MIDI/action feedback and active-control highlights
- Automatic MPK/Akai MIDI source selection
- Local configuration with no account, API key, analytics, or network requests
- Universal binary for Apple silicon and Intel Macs

## Important knob setup

Turn **Internal Sounds off**, then learn the assignable **Filter**,
**Resonance**, **Reverb**, and **Chorus** knobs. The separate Volume knob
controls hardware audio and does not send an assignable MIDI message.

## Install

Download `MPK-Codex-Bridge-macOS.zip`, unzip it, and move the app to
Applications. This community build is not Apple-notarized, so first launch
requires Control-click > Open (or Privacy & Security > Open Anyway).

Requires macOS 13 or newer and the Codex desktop app.
